# Hoffmann FC Hub

Crear una web para Hoffmann FC integrando los dos archivos adjuntos (index.html que corresponde a Seguro Deportivo y reglamento.html que corresponde a Reglamento Interno) como pestañas de una misma web.

Requisitos:
1. Mantener exactamente el diseño, colores, fuentes, botones y contenido tal como están en los archivos adjuntos.
2. El Seguro al final muestra una confirmación de lectura; agregar exactamente el mismo mecanismo y formulario de confirmación al final del Reglamento.
3. Página principal que tenga la misma identidad visual y permita abrir un Google Form (dejar botón con enlace placeholder mientras se define el URL definitivo).
4. Base de datos para registrar quién confirmó la lectura (nombre, DNI/identificación, documento confirmado, fecha y hora).
5. Panel de administración en una URL /admin, simple y directo sin clave, que muestre la tabla de quiénes ya confirmaron tanto el reglamento como el seguro.
